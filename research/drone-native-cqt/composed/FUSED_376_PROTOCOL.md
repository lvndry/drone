# Prospective frozen 376-case frontend expansion

This packet prepares a wider test of the Mac-qualified fused-product rule. The
nine retained goldens passed, including a 28-minute recording. No decoding,
compilation or 376-case CQT execution is asserted here.

## Fixed references and outcome

`FUSED_376_MEMBERSHIP.json` freezes all 376 existing public cases in original
order: 126 Beatport and 250 FMAK. It joins the first 305 completed Mac records
with the final 71, excluding the separately retained duplicate early failure.
For every case it binds original audio/PCM, captured Mac manifest, original
native control core, archived Mac Python core, canonical Linux core and source
record identities. The observed decoded durations span 40.12–1,682.26 seconds.

The **primary gate** is 376 original native controls reproduced exactly and
376 candidate cores equal to their archived **Mac** Python reference hashes.
Canonical Linux core equality is a separately reported comparison; it cannot
replace a failed Mac comparison or turn Mac-only qualification into universal
platform equivalence. Numerical mismatches are retained and the fixed remaining
cases continue while resources permit. Artifact, runtime or resource failures
stop the attempt with partial evidence intact. No automatic retry, new formula,
reference switch, tolerance relaxation, case replacement or model run follows.

Existing Mac reference arrays were removed during the previous streamed run.
Their original hashes, manifests and kernels remain. Hash equality proves exact
identity; a different hash fails the gate. A missing reference array means a
failure's differing-value count and maximum error are unavailable. Do not
regenerate Python reference cores after observing a mismatch.

## Source admission and exact PCM recovery

Read-only preparation checked all retained Mac manifests and CSR banks against
their historical identities. On `lysk-server`, all 376 original public audio
paths exist; the archived producer, features, transport, guard, study, reference
report, goldens and ffmpeg match their recorded identities. All 376 canonical
reference metadata records match their enclosing report. Audio content hashes
are checked by the original producer at execution, not claimed by this metadata
inventory. Four protected serving-process identities were observed unchanged;
refresh the admission observation before sealing the launch.

The unchanged archived `cqt_pipeline_stage.produce()` checks each original audio
hash, decodes through the original feature source, and requires exact canonical
PCM bytes. It only decodes and copies invariant constants: no CQT or model call.
The prospective wrapper verifies the original module origins and forbids loaded
librosa, Torch or ONNX Runtime modules. No dependency installation is required.
Hash-bound source/runtime inputs and the final decoded PCM identity are required;
an environment mismatch is not a reason to substitute a decoder or waveform.

## Finite transport and native execution

Use one persistent SSH stream, one outstanding case, and 512 KiB I/O blocks.
The server calls the archived producer once, then the archived PCM-only
encode/decode helpers. Signed int16 transport is accepted only when exact
float32 roundtrip and the original PCM hash agree. The receiver independently
reconstructs and verifies that same float32 identity. There is no lossy fallback,
canonical core payload, Python reference computation or classifier invocation.

The receiver copies the retained, hash-verified Mac manifest and its CSR files
into the fresh case spool. `fused_public_case` admits only the compiled membership
entry, original manifest/PCM and pinned runtime. It first computes and retains
the separate-product control. If that control is exact, it computes and retains
the unchanged fused candidate. Every new core and case result remains retained;
a failed control withholds only that case's candidate and remains a failure.

Only after native evidence and received hashes are retained does the receiver
acknowledge the case. Both sides delete only their newly created acknowledged
PCM/transport spool, then proceed to the next fixed index. Preserve the first
numerical failure's full local PCM/plan spool as well; every later failure still
retains complete new core bytes, inputs' identities, result and logs. Input and
runtime failures preserve their unacknowledged spool. Historical data is never
deleted. A disconnected receiver ends the producer; each external guardian
retires only its own captured process identities.
